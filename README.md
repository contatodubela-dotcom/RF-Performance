# RF Performance Comercial

Aplicação web para planejamento, acompanhamento e desenvolvimento da operação comercial da RF Consórcios.

## Objetivo inicial

Apoiar o crescimento da operação de consórcio de automóveis por meio de:

- planejamento comercial;
- gestão de PDVs e equipes;
- metas e indicadores;
- treinamentos e avaliações;
- feedbacks;
- reuniões;
- planos de ação;
- acompanhamento do plano de 90 dias.

## Arquitetura

- Frontend: React, TypeScript e Vite
- Interface: Tailwind CSS
- Banco e autenticação: Supabase
- Código-fonte: GitHub
- Hospedagem: Cloudflare Pages

## Independência técnica

O RF Performance Comercial possui infraestrutura própria, separada da EPSA Core e do MCI.

O projeto não utiliza banco, credenciais ou serviços da OnSpace.

## Status atual

Fase 0 — auditoria, limpeza e preparação da fundação técnica.

As migrations definitivas do Supabase serão criadas e versionadas nas próximas etapas.
